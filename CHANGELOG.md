# Changelog

Los cambios notables seguirán una versión simplificada de Keep a Changelog y versionado semántico cuando exista software publicable.

## [1.0.0] - 2026-07-31

### Added

- Definición completa de Fase 0.
- Dirección visual Calm Momentum.
- Estrategias SQLite, futura migración PostgreSQL, LocalStorage y contenido JSON.
- Arquitectura VitePress y GitHub Pages.
- Roadmap secuencial, ADR y archivos de gobernanza.
- Monorepo pnpm con React, FastAPI y paquetes compartidos.
- SQLite mediante SQLAlchemy y migración Alembic reversible.
- Adaptador LocalStorage tipado y versionado.
- JSON Schema y validación Ajv.
- Tokens, componentes y shell responsive Calm Momentum.
- Sitio VitePress con búsqueda, Mermaid y navegación.
- CI rápida y Dependabot.
- Voz Realtime WebRTC mediada por backend con fallback local.
- Sesiones y feedback de aprendizaje persistentes en SQLite.
- Revisión posterior a la práctica con recuperación sin conexión.
- Consentimiento explícito para guardar transcripciones de texto.
- Historial, racha y progreso agregados sin retener texto por defecto.
- Aplicaciones Android e iOS mediante Capacitor 8.
- Caso de estudio, tarjeta social, guion de demo y flujo de GitHub Pages.

### Security

- Límites explícitos para secretos, audio, transcripciones y datos públicos.
- Cabeceras seguras, límites HTTP, CORS nativo y logs sanitizados.
