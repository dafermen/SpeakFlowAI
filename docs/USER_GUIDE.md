# Guía de uso

## Primera entrada

1. Escribe el nombre con el que quieres que te llamemos.
2. Elige tu nivel aproximado de inglés.
3. Selecciona al menos un objetivo y un tema.
4. Ajusta voz, velocidad y ayuda breve en español.
5. Revisa el resumen y entra a SpeakFlowAI.

El avance del onboarding queda en este navegador. Si cierras la página, puedes
continuar desde el último paso.

## Iniciar una práctica

Desde **Inicio**, elige **Iniciar práctica**. Selecciona uno de los cuatro modos,
revisa nivel y duración, y decide entre:

- **Comenzar con voz**: usa micrófono y WebRTC. Requiere que la API tenga una
  credencial de OpenAI configurada.
- **Usar demo local**: permite completar el recorrido escribiendo respuestas y
  funciona sin red ni credenciales.

Durante la sesión puedes pausar, silenciar, pedir repetición, solicitar un ritmo
más lento y alternar subtítulos.

## Entender la revisión

Al terminar verás un resumen, una fortaleza, un área de enfoque, correcciones,
vocabulario y frases reutilizables. **Guardada** indica que la API persistió la
sesión. **Copia local** indica que puedes leer el feedback, pero conviene usar
**Reintentar guardado**.

## Consultar progreso

Abre **Progreso** en la navegación principal para ver:

- sesiones y minutos acumulados;
- intervenciones realizadas;
- racha de días;
- modos practicados y áreas recurrentes;
- las cinco sesiones más recientes.

Las métricas funcionan aunque las transcripciones estén desactivadas.

## Preferencias y privacidad

En **Más** puedes cambiar tema, subtítulos, ayuda en español y retención de
transcripciones. Esta última opción está apagada por defecto. SpeakFlowAI nunca
guarda audio.

Consulta [Feedback y retención](FEEDBACK_AND_RETENTION.md) para conocer los datos
exactos que se almacenan.
