# Guion de demo

Duración objetivo: 90 segundos. Usar solo datos ficticios y la demo local para
que la grabación sea reproducible.

1. **0:00–0:10 · Problema.** “Entender inglés no siempre significa sentirse listo
   para hablarlo.” Mostrar Inicio.
2. **0:10–0:25 · Elección.** Abrir Prácticas, elegir cafetería y revisar nivel y
   duración.
3. **0:25–0:50 · Conversación.** Usar demo local, escribir dos respuestas y
   señalar subtítulos/controles.
4. **0:50–1:10 · Aprendizaje.** Terminar y mostrar fortaleza, enfoque, vocabulario
   y privacidad de la transcripción.
5. **1:10–1:25 · Progreso.** Abrir dashboard y señalar sesiones, minutos y áreas.
6. **1:25–1:30 · Cierre.** Social card y frase “Practice English. Build confidence.”

Revisar que la captura no muestre notificaciones, nombres reales, claves, rutas
personales ni barras del sistema innecesarias. Añadir subtítulos al video.
