# Contenido de aprendizaje

Esta carpeta contendrá contenido estático versionado. En Fase 1 solo existe el esquema de escenario necesario para validar la infraestructura; los catálogos se incorporan en Fase 2.

Reglas:

- IDs estables y texto mediante claves localizables.
- Solo ejemplos sintéticos.
- Todo archivo debe validar antes del build.
- Los datos modificados por el usuario pertenecen a SQLite, no aquí.
